# TADR-NNNN: Decision-Focused Title

- Status: Proposed
- Date: YYYY-MM-DD
- Deciders: Maintainers
- Related: None

## Context

State the facts, constraints, forces, and decision drivers without advocating for an
option.

## Decision

State the proposed or accepted decision directly, including testable invariants.

## Options Considered

Describe credible alternatives at comparable depth, including the current approach when
it remains viable.

## Consequences

Record positive, negative, and neutral consequences, including migration and operational
effects.

## Confirmation

Name the tests, reviews, automation, or linked delivery evidence that confirms the
decision is followed.
